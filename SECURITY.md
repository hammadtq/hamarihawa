# Security

If you find a security problem in the site or this code (for example a way to read or change the site's data, or to make the Worker fetch something it shouldn't), please email hello@hamarihawa.org instead of opening a public issue. We'll reply as soon as we can.

The site holds no accounts or personal data. Visitor location for "your air" is worked out per request from Cloudflare's IP lookup and is never stored.
